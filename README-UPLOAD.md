# Upload these to your profile repo

Upload **both SVG files** into `https://github.com/gitOfKuKue/gitOfKuKue` (same folder as `README.md`):

1. `github-contribution-grid-snake.svg`
2. `github-contribution-grid-snake-dark.svg`

## Quick way (GitHub website)

1. Open https://github.com/gitOfKuKue/gitOfKuKue
2. Click **Add file → Upload files**
3. Drop the two `.svg` files from this folder
4. Commit
5. Also paste the updated `gitOfKuKue.md` content into `README.md` and commit

The snake will appear on your profile after both the README and SVGs are on `main`.
